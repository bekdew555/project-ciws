# Project CIWS — Close-In Water System

ระบบป้องกันระยะประชิดด้วยน้ำ ไล่นกพิราบออกจากระเบียงแบบไม่ทำร้าย ด้วยหลักการเดียวกับป้อมปืน Phalanx CIWS บนเรือรบ

งานนำเสนอคอนเซ็ปต์ระบบอัตโนมัติ เป็นเว็บหน้าเดียว (`index.html`) มี:

- สไลด์ 16 หน้า เปลี่ยนหน้าแบบเข้าออก
- แผนภาพออกแบบ: ภาพรวมระบบ, แบบตัวป้อม, ผังวงจร, state machine, การคำนวณการเล็ง, แอปมือถือ
- แบบจำลอง 3 มิติ (Three.js) ที่กดเล่นได้ รวมถึงทดสอบ IFF ด้วยแมว

## การใช้งาน

เปิด `index.html` ในเบราว์เซอร์ (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และ Three.js)

- `→` / `Space` สไลด์ถัดไป · `←` ย้อนกลับ · `F` เต็มจอ
